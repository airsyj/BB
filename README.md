# 市政工程进场出场报备系统

移动端报备 + 后台报表导出。含四个报备模块与续期功能，导出表格与提供的 Excel 模板结构一致。

## 启动
```bash
cd report-system
node server.js
# 默认 http://localhost:3000
# 后台 http://localhost:3000/admin
```

## 模块
- 人员报备：拍身份证正反面 → 自动识别姓名/身份证号/有效期，填手机号。
- 车辆报备：拍驾驶证、行驶证（含副页）、驾驶员身份证 → 自动识别并采集车牌/品牌/型号/年检/有效期等。
- 物资进场 / 物资出场：物品名称、单位、数量 + 关联车辆 + 进场/出场时间（出场需手机号）。
- 续期报备：输入身份证号或手机号查询历史，带入信息后上传通行证或填写新有效期。

## 后台导出
打开 `/admin`，输入 token（默认 `admin123`，见 `config.json`），可分别下载
「人员信息 / 司机信息 / 物资进场 / 物资出场 / 全部」Excel（.xlsx）。

## 配置 `config.json`
- `adminToken`：后台管理口令，请务必修改。
- `passValidDays`：报备后默认可通行天数（默认 30）。
- `ocr.baidu.apiKey` / `secretKey`：填入百度智能云 OCR 密钥后，证件拍照即自动识别。
  未配置时系统自动降级为手动填写，其余功能不受影响。

## 接入 OCR（最准确方案）
当前默认对接 **百度智能云 OCR**（身份证/驾驶证/行驶证结构化识别，准确率高）。
如需更换厂商，修改 `lib/ocr.js` 中的 `ocr()` 即可。配置密钥后，手机拍照即时回填字段。

## 部署到线上（手机/电脑均可访问，免费）
完整免费的云端部署步骤见 **[部署指南.md](部署指南.md)**：将本目录推送到 GitHub，
连到 Render 或 Koyeb 免费档，设置环境变量（至少 `ADMIN_TOKEN`）即可获得公开网址，
任何人用手机或电脑打开即可填报，无需你一直开着电脑。配置密钥一律走环境变量，
`config.json` 仅留在本机、不会被上传。上传的证件照片保存在 `uploads/`，数据保存在 `data/reports.json`。
